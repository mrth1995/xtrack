<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to service worker cache | Browser requests may be served from generated Workbox precache. |
| user agent to install guidance | User agent and install prompt state control instructional UI only. |
| offline shell to authenticated content | Cached app shell must not leak private API responses. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Information Disclosure | `vite.config.ts` Workbox config | mitigate | Use precache glob patterns for client/prerendered static assets only; do not add Supabase REST/action runtime caching. |
| T-04-06 | Spoofing | `InstallGuidanceBanner.svelte` | accept | Banner does not authenticate or collect secrets; it only displays browser install instructions. |
| T-04-07 | Denial of Service | service worker update lifecycle | mitigate | Use `registerType: 'autoUpdate'` so stale shell updates automatically. |
| T-04-08 | Information Disclosure | standalone restore/offline notice | mitigate | Offline notice copy contains no user data and cached shell must not include private API cache rules. |
</threat_model>
