<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to service worker cache | Browser requests may be served from generated Workbox precache. |
| installed app metadata to OS launcher | Manifest and icon metadata are consumed by iOS/Android home-screen launchers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Information Disclosure | `vite.config.ts` Workbox config | mitigate | Use precache glob patterns for client/prerendered static assets only; do not add Supabase REST/action runtime caching. |
| T-04-06 | Denial of Service | service worker update lifecycle | mitigate | Use `registerType: 'autoUpdate'` so stale shell updates automatically. |
| T-04-07 | Tampering | PWA icon/manifest assets | accept | Assets are static repo-controlled files with no user input path. |
</threat_model>
